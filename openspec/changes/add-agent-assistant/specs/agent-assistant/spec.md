## Purpose

将 CampusClaw 单次、无状态、提示词硬编码的 AI 解题助手升级为可配置、带「解题引导」技能、支持多轮会话与 SSE 流式输出的对话式智能体，并保持既有的班级知识库检索与溯源、每日限次与班级数据隔离约束。

## ADDED Requirements

### Requirement: 教师的可配置提示词

教师 MUST 能按班级自定义 AI 解题助手的系统提示词，并能在任意时刻保存与重新读取。系统 MUST 将配置持久化（每班一份），教师留空提示词时 MUST 回退到内置默认提示词。教师 MUST 只能配置其任教班级（`teaching_classes` 范围内），越权配置 MUST 返回 403 并记录审计日志。

#### Scenario: 教师保存某班自定义提示词

- **WHEN** 教师在任教班级（如 class_id=101）保存一份自定义系统提示词
- **THEN** 系统将其持久化到该班级的 AgentConfig，学生在该班提问时使用该提示词

#### Scenario: 留空回退默认提示词

- **WHEN** 教师清空某班级的自定义提示词（或从未配置过）
- **THEN** 学生在该班提问时使用内置默认提示词（含 LaTeX 公式定界符与元话语禁令）

#### Scenario: 配置非任教班级被拒绝

- **WHEN** 教师尝试保存或读取一个不在其 `teaching_classes` 内的班级配置
- **THEN** 系统返回 403 Forbidden 并记录审计日志

### Requirement: 「解题引导」技能开关

教师 MUST 能按班级开关「解题引导」技能。系统 MUST 将开关状态持久化并应用到学生提问时的提示词拼接：开启时，MUST 在系统提示词中追加"只给思路引导、不直接给最终答案"的技能规则；关闭时不追加。系统 MUST 向教师提供技能文案预览。

#### Scenario: 开启解题引导技能

- **WHEN** 教师在班级开启解题引导技能后学生提问
- **THEN** 系统将技能文案并入系统提示词，AI 只给解题思路引导、不直接给出完全最终答案

#### Scenario: 关闭解题引导技能

- **WHEN** 教师在班级关闭解题引导技能后学生提问
- **THEN** 系统不追加技能文案，AI 按默认提示词直接给出分步解题与结论

#### Scenario: 教师预览技能文案

- **WHEN** 教师编辑技能配置或点击技能文案查看
- **THEN** 系统返回"给思路不给答案"的技能文案内容供教师了解并确认

### Requirement: 多轮会话与上下文延续

学生 MUST 能创建多个会话并进入其中一个会话发起连续追问。同一会话内的历史消息（最近的若干轮）MUST 作为上下文在生成回答时传递给大模型，使追问能延续前文。会话 MUST 属于创建它的学生且绑定提问时的班级，读取/删除/追问会话 MUST 校验归属与班级一致，越权（篡改会话或跨班级访问）MUST 返回 403。

#### Scenario: 在会话内连续追问

- **WHEN** 学生在同一条个会话内连续发送"什么是向量夹角？""具体怎么算？"等追问
- **THEN** 系统把该会话前几轮的用户与 AI 消息一并作为上下文传给大模型，使"具体怎么算"能接着前文展开

#### Scenario: 新建与列出会话

- **WHEN** 学生点击"新对话"提交问题（或主动创建会话）
- **THEN** 系统创建一个绑定该学生与当前班级的新会话，并在会话列表中可见；问题作为首条消息、以其截断作会话标题

#### Scenario: 访问他人会话被拒绝

- **WHEN** 学生尝试读取或追问一个不属于本人，或属于其他班级的会话
- **THEN** 系统返回 403（非本人）或 404（不存在），并记录审计日志

### Requirement: 删除会话

学生 MUST 能删除本人当前班级下的会话。删除会话 MUST 连同其全部消息一并移除（SQLite 未启用外键级联，需显式清空 `messages` 再删 `conversations`）。删除不存在的会话或他人会话 MUST 返回 404。

#### Scenario: 删除会话并清理消息

- **WHEN** 学生删除某会话
- **THEN** 系统删除该会话及其全部 user/assistant 消息，删除后读取该会话消息返回 404

### Requirement: SSE 流式回答

学生提问后，系统 MUST 以 SSE（`text/event-stream`）方式逐字流式返回 AI 回答，而非一次性整体返回。流式过程 MUST 携带增量文本事件与结束事件（含最终答案、溯源引用与剩余可用次数）；调用 DeepSeek 失败或未配置 API Key 时 MUST 以降级文案流式返回（展示检索到的相关段落），不置视为整体失败。反向代理 MUST 关闭对 `/api/` 的响应缓冲以保证流式逐字生效。

#### Scenario: 流式逐字输出

- **WHEN** 学生在会话内提问且 DeepSeek 正常
- **THEN** 前端逐字渲染流式增量，最后收到含最终答案、citations 与 remaining 的结束事件

#### Scenario: 检索无命中时返回降级提示

- **WHEN** 本班没有相关分块被召回
- **THEN** 系统流式返回"暂无相关班级资料，暂无法回答「问题」"的降级文案（不调用大模型）

#### Scenario: DeepSeek 失败时降级为检索段落

- **WHEN** 有相关分块但 DeepSeek 调用失败或未配置 API Key
- **THEN** 系统流式返回"AI 生成服务暂不可用 / 未配置 API Key，暂仅展示检索到的相关段落"，并把召回段落一并返回

#### Scenario: 流式结束写回会话

- **WHEN** 流式完成（无论成功或降级）
- **THEN** 系统把本条 user 消息与最终 assistant 消息（含溯源 sources）写回该会话，保证后续继续追问有上下文

### Requirement: 消息与会话持久化

系统 MUST 将会话内的每条消息（role 为 user 或 assistant）持久化到 `messages`，assistant 消息 MUST 额外持久化其溯源引用（`sources`，JSON 数组）。读取会话消息 MUST 按时间正序返回，供前端回显历史与继续追问。历史作为上下文时 MUST 仅取有限轮次（避免超出模型上下文长度）。

#### Scenario: 回显历史消息

- **WHEN** 学生重新打开某会话
- **THEN** 系统按时间正序返回该会话全部 user/assistant 消息，assistant 消息携带其溯源引用

#### Scenario: 仅带最近若干轮作为上下文

- **WHEN** 会话消息很多、学生继续追问
- **THEN** 系统只取最近若干轮（如最近 6 条 user/assistant 消息）作为上下文，避免历史过长

### Requirement: 兼容既有约束

多轮会话与流式提问 MUST 与既有功能共享约束：AI 提问计数 MUST 复用 `AIQuestionLog` 按自然日统计（每日 20 次上限，超限返回 429 并记审计）；班级数据隔离 MUST 仍经 `require_student_class_id` / JWT `class_id` 强制，检索仍经 `retrieve_top_k` 限定本班（含 `citations` 溯源）；未分配班级的学生进入问答 MUST 被拒绝（403，前端展示"暂无班级"空状态）。

#### Scenario: 追问计入每日限次

- **WHEN** 学生在会话内每次连续追问
- **THEN** 系统每次计数到当日 20 次限额，达到上限后返回 429，流式结束事件携带剩余次数

#### Scenario: 未分配班级学生被拒

- **WHEN** class_id 为 NULL 的学生尝试创建会话或追问
- **THEN** 系统返回 403，前端展示"暂无班级"空状态，不发请求

#### Scenario: 教师配置与班级检索共享隔离

- **WHEN** 学生提问命中本班分块
- **THEN** 回答仍带 `citations` 溯源且全部来自本班范围，与 `add-rag-search` 行为一致
